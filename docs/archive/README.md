# Archive

Early planning documents, kept for history. They are **not** kept up to date and no longer describe how the tools work — the
code, the help pages and the main [README](../../README.md) do.

- `kiro-specs/` — the original Kiro specs (requirements, design, tasks) for VE Table Tuning, the Knock Analyzer and Injector
  Characterization, May 2026. Since then the tools changed a lot; for example, knock is now measured as stretches above the tune's
  own Knock Threshold table, not as single samples above a fixed 5 %.
- `rag-architecture.md` — design of the tuning-knowledge MCP server (training-video transcripts and MoTeC documents behind a search
  tool). That server lives outside this repository.
