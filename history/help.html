Tuning History — Help

The tuning history keeps the results of your analysis runs so you can follow a calibration over time: change the tune, log, analyze, save — and see whether the numbers improved.

Saving a run

After an analysis on VE Table Tuning, the Transient Fuel Analyzer, the Knock Analyzer, DI Fuel Pressure, Log Health, Ignition Review, Closed-Loop Period or the Pull Report, add an optional note (for example "after VE V56") and click Save to tuning history. Runs are only saved when you ask, so experiments with different settings don't clutter the history; saving again adds another run.

Each run keeps the log's name, start time and ECU serial (from the log), the tune the tool used, the settings, and the key results. The log itself is not stored.

With the pages served by a TunerControl server, runs are stored in its database and every browser sees them (and the server backup includes them). Otherwise they are kept in this browser only.

The history page

Choose a tool. The table lists its runs, newest first, with the main results; Details shows the stored advice and figures, Note edits the note and Delete removes the run. The charts below put the runs in log order:

ToolCharts
VE Table TuningMean correction still needed and the number of cells needing more than 2%. The latest run's grid: click a cell to see its correction in every run (matched by its MAP and rpm breakpoints).
Transient FuelAverage lean spike and rich overshoot on tip-ins, and how many tip-ins go rich first.
KnockThe typical knock level of each cylinder (the sensor check) and the number of knock events. After fixing a knock sensor, its cylinders should rise to the level of the others.
DI Fuel PressureShare of time within ±2 bar of aim, and — for runs analyzed with a tune — how often pressure overshoots or lags a rising aim.
Log HealthThe number of failed and "check" findings. A fixed sensor or setting drops out of the list.
IgnitionKnock margin (the loudest cylinder's 99th percentile against Knock Threshold), seconds of steady-load timing ≥ 1° off the tune, and each cylinder's typical knock level — the even cylinders on Knock Input 2 should rise once that input is fixed.
Closed-Loop PeriodThe measured lambda delay and Fuel Closed Loop Period at each exhaust flow site: after a Period change the two should meet.
PullsThe leanest lambda against aim, the loudest knock and the largest rail-pressure shortfall in any pull of the run.

Closed-Loop Period and Pull Report runs can cover several logs: the run lists all their names and sorts by the earliest.

Tip: Compare like with like. A run from a drive with several boost pulls and one from a cruise will differ even with the same tune; the note is a good place to say what the drive was.
