Download a backup

Saves every imported tune with its original .m1pkg file, your resource names and labels, the tuning history, every harness with all of its revisions, harness systems with their joins and CAN networks, harness pictures, and this browser's page settings. Keep it somewhere other than the server.

Restore a backup

Adds everything in the backup that isn't stored here yet. Anything already here with the same id is kept as it is — nothing is deleted or overwritten (resource names, labels and page settings are set from the backup) — so restoring twice is safe. Backups from the M1 Config Viewer's older Export backup restore too.
