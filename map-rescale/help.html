MAP Rescale — Help

When the Inlet Manifold Pressure Sensor Translation changes, every reading changes — and with it which cell of every MAP-indexed table the ECU uses, and the air mass the fuel model calculates. This page converts the tune so the engine behaves the same at the same sensor voltage under the new translation. Then you re-tune from logs on a correct pressure scale instead of starting over.

Why not a flat VE multiplier

A translation is a line: kPa = offset + slope × volts. Changing it changes both, so the ratio between the old and the new reading is different at every pressure (e.g. −32.5/425 → −17/353 kPa: ×1.13 at 100 kPa but ×1.36 at 20 kPa). A single multiplier is right at one pressure only.

What it converts

  • Engine Efficiency on a MAP axis: re-read at the old reading of each site's voltage, then × old ÷ new reading. Air mass is proportional to VE × MAP, so the air mass at every voltage stays the same.
  • Tables on a MAP axis (mixture aim, fuel timing, film, closed-loop limits…): re-read along the axis; values unchanged in meaning.
  • Tables on Engine Load Normalised (ignition, alternative fuel ignition, cylinder trims, knock…) when Engine Load Normalised Mode is Inlet Manifold Pressure — then Load Normalised % equals the MAP reading in kPa (MoTeC M1 training 49).
  • Tables whose values are MAP readings (Inlet Manifold Pressure Estimate, MAP windows) — converted value by value; 0 means off and stays.
  • Settings compared with MAP (e.g. Fuel Closed Loop Activate Inlet Manifold Pressure): thresholds converted like a reading, hysteresis and rates scaled by the slope ratio, 0 left alone.

Tables whose MAP axis has a single site don't depend on MAP and are left alone. Ambient Pressure has its own sensor translation and is not changed.

Keep or move the sites

  • Keep the axis sites (default): the tables keep their round-number sites and each value is read from the old table, interpolated between its sites and clamped at its ends as M1 does. Paste the values straight into the existing tables. Between sites the result is an interpolation of the old table, so it is very close to exact but not perfectly so.
  • Move the axis sites: every value stays (Engine Efficiency still × old ÷ new) and each pressure site moves to the new reading of its voltage. This is exact, but you type the new sites into M1 Tune, and they are no longer round numbers.
Held cells (orange). With the sites kept, an Engine Efficiency site whose voltage read below the old table's lowest site has no old value to convert — and readings far below the old table are exactly what a bad translation produces on decel. These cells get the value of the nearest converted row so the table stays continuous; re-tune them from logs.

Typical use

  1. Establish the new translation (sensor data sheet, or two points: key-on engine-off against real barometric pressure, and a vacuum pump or boost gauge).
  2. Choose the tune. The old translation is filled in from it — if some of its tables were already converted (e.g. VE rescaled but the other axes not), enter the translation those tables were made for and paste only the tables that still need it.
  3. Enter the new translation, or take it from a tune that already has it.
  4. Convert, type the new translation into Inlet Manifold Pressure Sensor Translation, paste each table (Engine Efficiency Main can also be downloaded as an M1 Tune table CSV), and change the listed settings.
  5. Log a drive and run VE Table Tuning — the converted VE is the starting point, not the answer.
Paste order: the grids show pressure rows highest first, like an M1 Tune table CSV. Check one row in M1 Tune after pasting.
