MAP Rescale

Converts a tune to a new Inlet Manifold Pressure sensor translation so the engine runs the same at the same sensor voltage: every table on a manifold pressure axis (and on Engine Load Normalised when its mode is Inlet Manifold Pressure — ignition, knock), the settings compared with MAP, and Engine Efficiency scaled by old ÷ new reading. A translation change is an offset and a slope, so a flat VE multiplier can't do this.
