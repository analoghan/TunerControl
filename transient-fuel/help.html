Transient Fuel Analyzer — Help

Analyzes throttle transient events in MoTeC logs to diagnose fuel film table calibration. Identifies lean spikes on tip-in and rich overshoot, then recommends fuel film primary and time constant adjustments.

Prerequisites

Before using this tool, the following must already be calibrated:

  1. VE Table — must be dialed in so that at steady-state conditions, lambda hits the target. If your VE table is off, transient analysis will be meaningless.
  2. Injection Timing — must be optimized for your engine. Poor injection timing increases the amount of fuel film compensation needed.
  3. Charge Cooling Gain — must be calibrated so the ECU correctly accounts for charge air temperature effects on fueling.
  4. Closed Loop Lambda — should be disabled or its correction noted. The tool works best with open-loop data where lambda directly reflects VE + fuel film accuracy.
Important: If your VE table is not calibrated, this tool will show transient errors that are actually steady-state VE errors. Always dial in VE first, then address transient fueling.

How Fuel Film Works in MoTeC M1

When fuel is injected onto the intake port walls (port injection), some fuel sticks as a "film" rather than entering the cylinder immediately. During throttle transients:

  • Tip-in (throttle opening): MAP rises rapidly. More fuel sticks to the walls because the pressure/temperature conditions change. Without compensation, the engine momentarily runs lean.
  • Tip-out (throttle closing): MAP drops rapidly. Fuel that was stuck to the walls now evaporates and enters the cylinder. Without compensation, the engine momentarily runs rich.

MoTeC's fuel film model predicts how much extra fuel to add (or subtract) during these transitions using three main components:

Fuel Film Primary Table

A MAP-based table that defines how much fuel film compensation to apply as a percentage. Higher values = more compensation for larger MAP changes. This is the main table you tune.

Fast Time Constant

Controls the initial burst of compensation. The "percentage" setting (20-50% recommended) determines how much of the primary table value is applied in the fast phase. The increase/decrease time constants control how quickly it ramps on and off.

Fast increase time constant: How quickly the fast compensation ramps on (lower = faster). Typical: 0.1-0.3s

Fast decrease time constant: How quickly the fast compensation ramps off (lower = faster). Typical: 0.1-0.2s

Slow Time Constant

Controls the sustained compensation after the fast phase. This handles the longer-term fuel film behavior as the walls reach thermal equilibrium at the new operating point.

Slow increase time constant: How quickly the slow compensation builds (lower = faster). Typical: 0.3-1.0s

Slow decrease time constant: How quickly the slow compensation decays (lower = faster). Typical: 0.1-0.5s

Input Parameters

MoTeC Log File

A CSV export from MoTeC i2. Required channels:

  • Time — sample timestamps
  • Inlet Manifold Pressure — MAP for detecting transients
  • Exhaust Lambda Bank 1/2 (or Exhaust Lambda) — actual lambda measurement

Optional but recommended:

  • Fuel Mixture Aim — target lambda (if absent, uses the manual setting)
  • Engine Speed — for RPM context in the event table
  • Throttle Position — additional context
  • Coolant Temperature — for warm-engine filtering

Fuel Film Primary (.m1pkg or .csv, optional)

Select the M1 Tune package (.m1pkg) the log was recorded with. The tool reads Fuel Film Primary Main from it and fills in the Fuel Film Scale, Offset, Fast Percentage and the four time constants from the same tune, so there is nothing to copy by hand. The line under the file input shows which tune was read.

The time constants are small tables in M1 Tune (by coolant temperature; Fast Part by engine speed). When one has more than one site, the tool reads it at 90 °C, or at the Fuel Film Primary Reference Engine Speed for Fast Part, and says so under the file input.

A CSV export of Fuel Film Primary Main (M1 v2 format) still works; then enter the scale, offset and time constants yourself. Either way, Fuel_Film_Prim_Main_Corrected.csv imports back into M1 Tune.

MAP Rate Threshold (default: 200 kPa/s)

The minimum rate of MAP change to qualify as a transient event. Lower values detect more events (including mild throttle changes); higher values only catch aggressive tip-ins.

Recommended: 150-300 kPa/s for street driving logs. 300-500 for track/dyno pulls where throttle changes are more aggressive.

Min MAP Change (default: 15 kPa)

The minimum total MAP change for an event to be counted. Filters out small throttle adjustments that don't meaningfully exercise the fuel film model.

Lambda Target (default: 1.0)

Fallback target lambda if the "Fuel Mixture Aim" channel is not present in the log. If the channel exists, the tool uses the logged target value instead.

Understanding the Results

Tip-In Events (Lean Spikes)

Each row represents a detected throttle-opening event. Key columns:

  • Lean Spike % — How far lambda went above target (lean) during the transient. This is the primary indicator that fuel film primary values are too low.
  • Rich Overshoot % — How far lambda went below target (rich) after the initial lean spike. Indicates the compensation overshot — time constants may be too aggressive.
  • Recovery Time — Milliseconds until lambda settles within 2% of target. Long recovery = time constants need adjustment.
  • MAP Change — The transition zone (e.g., 40→80 kPa). Maps directly to which cells in the fuel film primary table need adjustment.

Severity Color Coding

  • Green (<5%) — Acceptable. Minor excursion, likely not noticeable in drivability.
  • Orange (5-10%) — Moderate. May cause a perceptible stumble or hesitation.
  • Red (>10%) — Severe. Will cause noticeable stumble, hesitation, or misfire risk.

Tip-Out Events (Rich Overshoot)

Throttle-closing events. Rich overshoot on tip-out indicates the fuel film model isn't removing compensation quickly enough when MAP drops.

Interpreting Recommendations

"Fuel Film Primary too low at X-Y kPa"

The fuel film primary table needs higher values in the specified MAP range. The suggested percentage increase is approximate — apply it, re-log, and re-analyze.

"Fast decrease time constant too slow"

After the initial burst of compensation, the fast phase is hanging too long, causing rich overshoot. Reduce the fast decrease time constant (e.g., 0.5 → 0.2).

"Slow decrease time constant too high"

On tip-out, the slow compensation isn't being removed quickly enough. Reduce the slow decrease time constant.

"Average recovery time >500ms"

Lambda takes too long to settle after transients. The slow increase time constant may need to be reduced so compensation builds faster.

Recommended Workflow

  1. Confirm VE is dialed in: Run the VE Table tool first. Corrections should be small (±2%) before addressing transients.
  2. Log transient data: Drive with varied throttle inputs — quick tip-ins from cruise, partial throttle sweeps, full-throttle launches. Hold each condition for 2-3 seconds between changes so lambda can settle.
  3. Run this tool: Load the log, review the lean spike severity by MAP zone.
  4. Adjust fuel film primary: Increase values in the MAP zones showing lean spikes. Start with the tool's suggested percentage.
  5. Re-log and check: Drive again, re-analyze. Lean spikes should be smaller.
  6. Tune time constants: If you see rich overshoot after fixing lean spikes, reduce the fast/slow decrease time constants.
  7. Iterate: Repeat until lean spikes are <3% and recovery time is <300ms.
Pro tip: Test at a fixed RPM on a dyno (e.g., 2000 RPM) with throttle sweeps between specific MAP breakpoints (30→40, 40→50, etc.). This isolates each cell in the fuel film table and makes calibration much faster than street driving.

Direct Injection Note

For direct injection engines, fuel film effects are significantly reduced because fuel is sprayed directly into the combustion chamber rather than onto intake port walls. You may find that fuel film primary values are much lower (or even zero) compared to port injection. However, DI engines can still benefit from transient compensation due to:

  • Injector response lag at very short pulse widths
  • Fuel pressure transients during rapid load changes
  • Air charge dynamics that the VE table doesn't fully capture

If you're running a DI engine and seeing minimal transient issues, the fuel film table may not need much calibration.

Troubleshooting

No events detected

Lower the MAP Rate Threshold (try 100-150 kPa/s) or the Min MAP Change (try 10 kPa). Your driving may not have included aggressive enough throttle changes.

All events show large lean spikes

If every event is severely lean regardless of MAP zone, check that your VE table is actually calibrated at steady-state. A globally lean VE table will show as transient lean spikes.

Events detected but lambda data is NaN

The wideband sensor may not be logging at a high enough rate, or there's a gap in the lambda data during transients. Ensure your log rate is at least 50Hz for lambda channels.
