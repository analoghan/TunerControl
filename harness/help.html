Harness Builder — Help

Getting started

  • Import spreadsheet (.xlsx) reads a harness workbook and saves it as revision 1.
  • Add from .xlsx… (in an open harness) copies connectors and splices from another workbook into this one, without touching the rest. Tick them by sheet or one at a time. A name the harness already has starts unticked: tick it to Replace yours (in the same place) or Add as a new name — connections among the added blocks follow the new name. Each block keeps its sheet, joining a sheet of the same name. Nothing is saved until you press Save; the checks run straight away.
  • Saved harnesses + Open opens one you saved before.
  • New harness starts an empty one; add connectors and splices, then Save.

The line under these says where harnesses are stored: on the TunerControl server (shared by every browser that uses it) or in this browser only. In browser-only mode, Export .xlsx is your backup.

Spreadsheet layout

Each connector or splice is a block of rows. Blocks are separated by blank rows and can be spread over several sheets — the sheet a block is on is kept and used to group the connector list.

X160
CONNECTOR   33472-1206
BOOT        N/A
MATE CONN   33482-6201
MATE PIN    33000-1002
NOTES       MX150
Location | Pin        | Conductor Part Number | Conductor Description | ECU Function        | Notes      | Remote Connection
1        | 33012-3002 | M22759/32-18-9PK      | 18 AWG White/Pink     | Direct Injector 1 + | M142 DI 1A+ | M142.A.7          |
…
  • The first row is the block's name. MoTeC ECU and expander titles are shortened for connections: MoTeC M142 A - 34 Way → M142.A, MoTeC E888 B - 26 Way → E888.B.
  • A splice block has a SPLICE row (the splice type) instead of CONNECTOR, and its table is Location | Conductor Part Number | Conductor Description | Function — one row per wire end joined in the splice.
  • The first seven columns are read by position, so their headings can be named however you like (e.g. MoTeC Function instead of Notes); they are kept and written back on export. The fifth is always shown as ECU Function (older sheets call it Engine Function).
  • Chassis Function (optional): free text for what a wire connects to outside this harness — e.g. Brake pedal switch, chassis loom. A column headed Chassis Function anywhere after Remote Connection is read and switches the column on for that connector. Turn it on or off per connector with the Chassis Function column box under the connector's fields; switching it off only hides it — text already entered is kept and still exported.
  • Any other columns (such as an old Status column) are not read.
  • Pictures placed beside a block (to its right, at or below its title row) are imported as that block's images.

How connections are written

The Remote Connection column (or a splice's Location) says where each wire goes:

Written asMeans
M142.C.14, CHAS.A.fCavity 14 of connector M142.C — the connector name, a dot, then the cavity.
M142.SPL.5VA1A splice, by its name.
CHASSIS, Cylinder Head, C0635-5GSomething outside this harness (no dot): a ground point, the vehicle's own wiring, … Shown as a warning, not an error.
UnterminatedThe wire is connected at this end only, on purpose — e.g. a cable shield or drain grounded at one end. A valid end: the checks don't look for the other one, and diagrams draw a capped stub. A note may follow in brackets: Unterminated (shield, ECU end). Also works for a wire in a splice's list.
EyeletA ring terminal on a stud or bolt (e.g. a ground point). A valid end, drawn as a ring. Add where it goes in brackets — Eyelet (engine block) — or put the keyword in brackets after it: Chassis Ground (Eyelet).
BatteryThe battery post. A valid end, drawn as a cell. Give the side with + or -: Battery +, Battery (-), Battery Negative (main ground).
DeviceWired straight into a device that has no connector of its own in this harness (a pigtail, a lamp, a motor). A valid end, drawn as a box. Name it in brackets — Device (fuel pump) — or Horn (Device).
N/A, Empty, Unused, blankNo connection. A cavity with a wire but no connection gets a warning; write Unterminated, Eyelet, Battery or Device if that's intended.

Every wire should be listed at both ends: if M142.C.14 goes to PEDAL.1, then PEDAL.1 should go to M142.C.14; a wire into a splice should appear in that splice's list. The checks verify this.

Saving, revisions and export

  • Save stores a new revision with an optional note. Unsaved changes appears until you do; the browser warns before you leave with unsaved changes.
  • Revision opens any earlier revision. Saving while viewing an old one makes it the newest revision (a restore); exporting it changes nothing.
  • Delete revision deletes only the revision you're viewing (after confirming). Revision numbers are never reused. The last remaining revision can't be deleted — use Delete to remove the whole harness.
  • Export .xlsx writes the harness in the same block layout, pictures included, so it can be re-imported or edited in Excel.
  • Export PDF builds a printable report and opens the print dialog — choose Save as PDF as the printer. Pick what goes in: the overview and system diagrams, the checks, each connector's and splice's table (with any problems beside the row), a wiring diagram per connector or splice, their pictures, and the tune comparison (all pins; choose a tune on that tab first). Diagrams stay sharp (vector) and are scaled to fit a page; Landscape prints wide ones larger. Unsaved changes are included and noted on the first page.

Editing connectors and splices

The Connectors and Splices tabs list blocks grouped by sheet, with their row count and a red (errors) or orange (warnings) badge. Type in Filter… to find one; Add connector / Add splice creates one.

  • Header fields — name, title, sheet, part numbers, boot, notes. Changing the name offers to update every connection that refers to it.
  • Rows — every cell is editable; changes are checked as you type.
  • ! / ? — an error or warning on that row. Hover for the message, click to open the details under the row with Use … (suggested fix) and Go to … buttons.
  • → — jump to the other end of the wire. If the connection points nowhere, the problem is shown instead.
  • ⤳ — trace the whole circuit from this row (see tracing).
  • × — remove the row (asks first). Add cavity / Add wire adds one.
  • Wiring diagram — this connector's diagram. Delete connector removes the block (asks first).

Connector images

Each connector and splice has an Images section — connector faces, pinout drawings, photos. Click a thumbnail for full size, type a caption under it, Add image for PNG/JPEG/GIF files, × to remove one. Images appear under the connector in its wiring diagram and are written back on export.

Each picture is stored once, however many revisions or connectors use it, so saving revisions doesn't copy them.

Checks

The Checks tab lists every problem; click Where to go to the row, or Use … to apply a suggested fix.

MessageWhat to do
Goes to "…", which is not a connector pin or splice in this harness — did you mean …?Usually a typo (M152.SPL…, M142.D15). Use the suggestion or correct it.
Goes to X, but X goes to "…"The two ends disagree. Decide which end is right and fix the other.
Goes to splice X, but the splice does not list …Add the wire to the splice's list, or correct the connection.
Goes to X, but X has no cavity "…"The connector exists but not that cavity — check the cavity name, or add the cavity.
Only matches ignoring upper/lower caseWorks, but write the name exactly (COIL1.3, not Coil1.3).
Extra text "(…)" after the connection was ignoredMove the extra text to the Notes column.
Wire part number differs from the other endThe same wire is listed with different part numbers at its two ends.
Has a wire but no remote connection / has a remote connection but no wire listedFill in the missing column, or clear the row.
Goes to "…", which is not defined in this harnessA warning for points outside the harness (ground lugs, vehicle wiring). Fine if intended.
Cavity appears more than once / name is used more than onceRename or remove the duplicate.

Two splices may be chained: a splice can list another splice as one of its ends, as long as both list each other.

Diagrams and tracing

The Diagram tab draws diagrams from the harness itself — they update as you edit. Choose what to show:

  • A connector or splice — its cavities on the left with each wire's gauge and colour, every wire drawn in its real colour (striped for two-colour wires, thicker for heavier gauge) to the pins it reaches, and splices followed through to their far ends. References to nothing appear as red Not in this harness boxes. Pictures are shown under the connector.
  • Overview — every connector and splice (ECU, splices, other connectors), joined by wire bundles with wire counts. Hover a box to highlight its bundles; click it to open its diagram.
  • System overview — each harness of the system with its mated connectors.
  • Circuit from … — after ⤳ on a row: every endpoint connected to it, through splices and across mated connectors into other harnesses, coloured by harness. Mated joins are drawn as ⇄.

Click a pin or endpoint to edit that row (opening the other harness if needed). Download SVG saves the diagram, with pictures, for printing or sharing.

Systems: harnesses that plug together

A system groups harnesses that connect to each other — e.g. an engine harness, a chassis harness and a transmission sub-harness. Each harness keeps its own revisions; the system ties them together.

How joins are found

Give both halves of a mating pair the same name in each harness (e.g. CHAS.A) and fill in their part numbers: the two are joined automatically when one's CONNECTOR part is the other's MATE CONN. Cavity A on one side then joins cavity A on the other.

Engine harness CHAS.A: CONNECTOR MS3476L22-95S, MATE CONN MS3474L22-95P

Chassis harness CHAS.A: CONNECTOR MS3474L22-95P, MATE CONN MS3476L22-95S → joined

Connections are always resolved within their own harness first, so CHAS.A.R in the chassis harness means the chassis side.

Setting up a system

  • Use the System list on the harness bar: pick a system, New system…, or None. The harness must be saved first.
  • When you import a workbook that plugs into a saved harness, you're offered to add it to that harness's system (or create one).
  • If one workbook holds both halves of a pair on different sheets (e.g. a TRANS Subharness sheet with its own TRANS plug), import offers to make that sheet a separate harness in the same system.

The System tab

  • Harnesses — members with Open and Remove (the harness itself is kept), Add to system, Rename system, Delete system (harnesses are kept).
  • Mated connectors — every join, marked automatic, manual or parts don't mate. Unlink removes a join; Same name, not joined lists pairs you unlinked or whose parts don't mate, with Link. Link manually joins any two connectors, e.g. ones with different names.
  • Checks across joins — a cavity wired on one side but not the other, a cavity defined on only one side, functions that disagree across the join, and linked connectors whose part numbers don't mate.

The system tab and diagrams use each other harness's latest saved revision, and the open harness as you're editing it.

CAN networks

A system can hold any number of CAN data networks (e.g. CAN 1 for the dash and PDM, CAN 2 for a keypad). Open the CAN networks tab of any harness in the system — the networks belong to the system, and every change is saved with it straight away (no Save needed).

  • Network — a name, its speed in kbit/s (125, 250, 500, 1000 …) and notes.
  • Devices — each device on the bus, the hub it plugs into, whether its own 120 Ω termination is on, and its speed. Leave the speed blank when it runs at the network's speed.
  • Hubs — tick which other hubs each hub is wired to. A new hub starts wired to the previous one.
  • Terminators — standalone 120 Ω terminators and the hub each plugs into.
  • Power — tick From CAN on a device that is powered through its CAN connection (+12 V and ground in the same cable as CAN-H/CAN-L).
  • Power feeds — where power enters the network: a name, where it comes from (e.g. PDM30 OUT 5) and the hub or device it feeds into.

Each network is checked: a bus needs exactly two terminations (60 Ω between CAN-H and CAN-L) — none or one is an error, more than two a warning with the resistance it gives; every device must use the network's speed; devices and terminators should be plugged into a hub; and all of a network's hubs must be wired together. Terminators not plugged into a hub don't count. A device powered from CAN needs a power feed that reaches it — power fed into a hub reaches every hub wired to it — and each feed needs a source and somewhere to go in.

Diagram (or CAN networks in the Diagram tab's list) draws the network: hubs in a row with their devices and terminators above and below, every connection as a twisted pair (yellow CAN-H, green CAN-L), each device's speed and termination, and anything not on a hub underneath. A connection that carries power gets two more wires beside its pair (red +12 V, black ground); a power feed is drawn as its own box with those two wires into its hub, or next to the device it feeds. Click a device, feed or hub to edit it. Export PDF can include the networks' tables and diagrams.

Tune comparison

Pick a tune imported in the M1 Config Viewer. Every I/O assignment in the tune is turned into its ECU or E888 pin and compared with what the harness wires there. In a system, choose Whole system (all harnesses — e.g. E888 pins in the chassis harness) or This harness only.

StatusMeaning
OK (Match)The harness function describes the same thing as the tune assignment.
CheckThe names don't look alike — e.g. tune Transmission Temperature on a pin the harness calls Inlet Air Temp. Often a real mismatch, sometimes just different wording (Auxiliary Output 2 vs IC Pump).
No wireThe tune uses the pin, but the harness has no wire there or marks it as spare.
Not matchedThe harness wires an ECU input/output that no named tune assignment uses — a function the tune doesn't use, something the package doesn't store (e.g. the crank reference), or an assignment that isn't named yet.
Not in harnessThe pin's connector isn't in this harness (e.g. the E888 when comparing the engine harness alone).
  • Problems / All pins switches between problems first and every pin.
  • Harness labels that don't match the pinout — the harness's MoTeC label column (e.g. AT6) disagrees with the datasheet pinout for that cavity.
  • Tune assignments without a known pin — I/O resources the viewer can't name yet. Name them with the Name button in the M1 Config Viewer and they're compared here too.
  • Direct injectors and bridge outputs use two pins; both are checked.

Suggested workflow

  1. Import the harness workbook(s). Accept the system and sub-harness offers if they apply.
  2. Work through the Checks tab: apply the suggested fixes, then the remaining errors. Save.
  3. Check the System tab's Checks across joins.
  4. Import the current tune in the M1 Config Viewer and open Tune comparison. Resolve every Check and No wire — either the harness document or the tune is out of date.
  5. Use the diagrams and circuit traces to confirm signals end to end; download SVGs for the build or the car's documentation.
  6. Save with a note after each round of changes; export .xlsx to share.

Troubleshooting

  • "No connector or splice blocks found" — each block needs a title row, then a row starting CONNECTOR or SPLICE, and a header row starting Location.
  • An image is on the wrong connector — pictures belong to the nearest block title at or above them. Move it with × and Add image, or move the picture in the spreadsheet and re-import.
  • Two harnesses don't join — the connectors need the same name and mating part numbers. Otherwise use Link manually on the System tab.
  • The arrow doesn't move — the connection points nowhere; the problem opens under the row.
  • Harnesses missing on another computer — browser storage is per browser. Use a TunerControl server, or export and re-import the .xlsx.
