Design and check wiring harnesses: connectors, cavities, wires and splices. Import an existing harness spreadsheet, edit it here, check every connection end to end, and compare the ECU pins against the I/O assignments in an M1 tune.

      System

      Harnesses that plug into each other. Connectors with the same name in two harnesses whose part numbers mate (one's connector is the other's mate connector) are joined automatically, cavity to cavity; circuits, diagrams and the tune comparison then follow wires across the joins.

      Checks

      Every remote connection is followed to the other end: references that point nowhere, ends that disagree, splices that don't list their wires, and wire part numbers that differ between ends.

      Tune comparison

      ECU and E888 pins used by the tune's I/O assignments, against what the harness wires to each pin. Uses the tunes imported in the M1 Config Viewer; names you give I/O resources there are used here too.

      Export PDF

      Builds a printable report of this harness and opens the print dialog: choose Save as PDF as the printer. Diagrams are scaled to fit a page.

      Pick the connectors and splices to add to this harness. Names it already has are unticked — tick one to replace yours or add it under a new name. Nothing is saved until you press Save.
